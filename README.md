# Portfólio — Pablo Henrique Oliveira Rodrigues

Portfólio pessoal (currículo online) desenvolvido como Atividade Prática do curso de Engenharia de
Software da UNINTER.

**Site publicado:** <https://pablo-rodrigues1.github.io/portfolio-pablo-rodrigues/>

## Seções

- **Sobre mim** — apresentação, informações pessoais e interesses
- **Formação** — graduação, formação técnica, tecnologias e idiomas
- **Portfólio** — links para os projetos publicados no GitHub
- **Contato** — formulário com validação em JavaScript e envio simulado

## Tecnologias

HTML5, CSS3 e JavaScript.

## Identidade visual

As formas seguem o sistema visual do
[Aetherius UI Core](https://github.com/pablo-rodrigues1/AetheriusUI_Core), um
projeto meu: superfícies planas de cantos retos, linhas finas e rótulos em
caixa alta. A paleta usa só preto, branco e cinza, com títulos em negrito, e
se inverte entre o tema escuro e o claro.

Os elementos gráficos (losangos e filetes) são feitos só com CSS, sem
imagens nem bibliotecas externas.

## Funcionalidades em JavaScript

- Validação do formulário (campos obrigatórios e formato do e-mail)
- Simulação do envio, com limpeza dos campos e modal de confirmação
- Tema claro/escuro, com a escolha salva no navegador
- Menu responsivo para celular
- Destaque no menu da seção que está sendo lida
- Animação de entrada dos blocos ao rolar a página

## Estrutura

```
portfolio-pablo-rodrigues/
├── index.html        página única, com navegação por âncoras
├── css/
│   └── estilo.css    estilos, temas e responsividade
├── js/
│   └── script.js     interações e validação
└── img/
    └── favicon.svg   ícone da aba do navegador
```

## Como executar localmente

Basta abrir o arquivo `index.html` no navegador. Não há instalação nem
etapa de build.
